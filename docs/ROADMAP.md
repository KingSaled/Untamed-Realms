# Roadmap

## v0.1 — Foundation (this milestone)
- [x] Repo, Gradle multi-project, CI with game tests and a full-pack server smoke test
- [x] Curated performance / QoL / worldgen modpack (packwiz, auto-resolved from Modrinth)
- [x] ur-core: Magicka & Stamina, Crowns economy, banners, chest loot injection, data registries
- [x] ur-skills: 24 skills, RuneScape XP curve, Skyrim character levels, 136 perks, requirements, skill books
- [x] ur-classes: 11 classes, 14 birthsigns, first-join character creation
- [x] ur-quests: quest engine, main story chapter 1, side quests, radiant bounties, journal, tracker, notice boards
- [x] ur-npcs: dialogue, shops, trainers, pickpocketing, self-populating villages
- [x] ur-magic: 5 schools, 23 spells, tomes, spellbook, HUD
- [x] ArtForge: sprites, NPC skins, 3D block models, Blockbench export

## v0.2 — Arsenal & crafting depth
- [x] **ur-arsenal**: Skyrim-style material tiers (Iron → Steel → Orcish → Dwarven → Elven → Glass → Ebony → Daedric)
  for daggers, swords, war axes, maces, greatswords, battleaxes, warhammers, bows; light & heavy armor sets;
  Better Combat weapon attributes; ArtForge templates for every tier.
- [x] Forge / tanning rack **crafting stations** gated by Smithing; tempering at a workbench (the workbench
  took the grindstone's role).
- [x] Rings & amulets as Curios accessories with enchant-like effects (SkillEffect powered).
- [x] Art design language: [ART_STYLE.md](ART_STYLE.md) + ArtForge lint in CI.
- [ ] Real **alchemy**: ingredients with hidden effects discovered by eating, an alchemy lab. *(ur-arcana, started; after the v0.2 playtest)*
- [ ] **Enchanting** overhaul: disenchant to learn, enchant with soul gems. *(ur-arcana, started; after the v0.2 playtest)*

## v0.3 — The living world
- Lockpicking minigame for locked chests/doors in our own dungeons.
- Crime & bounty: guards remember theft/assault per settlement; fines, jail, fleeing.
- Factions / guilds (Fighters, Mages, Thieves) with questlines and ranks.
- Horses & carriages between towns; inns with rentable beds (rested XP bonus).
- NPC schedules (work by day, inn by night), more archetypes and voiced-style barks.

## v0.4 — Story & dungeons
- Main story chapters 2–4 with unique dungeons (structure NBT generated by a new ArtForge structure builder).
- Dragons / world bosses with shouts-style powers unlocked by defeating them.
- Standing stones placed in the world to change birthsign.
- Radiant quest templates (dynamic targets: "clear the nearest dungeon").

## Ops
- Release workflow: tag → GitHub Release with mod jars + `.mrpack`.
- Custom title screen / loading screen branding (FancyMenu or our own).
- Default keybind profile resolving third-party conflicts (Default Options).
- Pre-generated spawn region and a hand-built capital city as the spawn hub.

# Content authoring guide

Almost everything in Untamed Realms is JSON loaded from datapacks, reloadable with `/reload`.
Add files under your own namespace (e.g. `data/myserver/urquests/quests/my_quest.json`) in a
datapack, or override ours by using the same path. Our defaults are generated by
`tools/datagen/*.py` — read those for many more examples.

Text fields (`name`, `title`, `description`, `text`...) accept a plain string or any JSON text
component (`{"translate": "..."}`, colours, etc.).

**Matchers** (used by XP tables, requirements, quest targets, shops): an exact id
`minecraft:diamond_ore`, a tag `#minecraft:logs`, `*` for anything, and in quests/shops several
alternatives joined with `|`.

---

## Effects (shared by perks, classes, birthsigns)
```json
{ "type": "damage_bonus", "key": "one_handed", "value": 0.2 }
{ "type": "attribute", "attribute": "minecraft:generic.max_health", "operation": "add_value", "value": 4 }
```
| type | key | meaning |
|---|---|---|
| `attribute` | – | attribute modifier (`attribute`, `operation`: add_value / add_multiplied_base / add_multiplied_total) |
| `damage_bonus` | skill id, or empty | outgoing damage +x (fraction) |
| `damage_reduction` | `heavy_armor`/`light_armor` (scaled by pieces worn), `block`, or empty | incoming damage −x |
| `xp_bonus` | skill id, `category:combat|magic|stealth|gathering`, or empty | skill XP +x |
| `extra_drop` | mining / woodcutting / farming / fishing | double-drop chance |
| `speed_bonus` | mining / woodcutting | gathering speed |
| `sneak_attack` | melee / archery / empty | added to the sneak-attack multiplier |
| `cost_reduction` | magic school id, or `stamina` | spell / stamina cost −x |
| `spell_power` | magic school id, or empty | spell magnitude +x |
| `price_bonus` | – | better merchant prices |
| `regen` | health / magicka / stamina | regeneration bonus |
| `potion_duration`, `loot_bonus`, `smithing_quality`, `food_healing`, `fall_reduction`, `stealth`, `pickpocket` | – | see names |

## Perks — `urskills/perks/<file>.json`
```json
{ "skill": "mining", "perks": [
  { "id": "rock_breaker", "name": "Rock Breaker", "description": "Mine 15% faster.", "level": 20,
    "requires": ["prospector_1"], "cost": 1, "effects": [ { "type": "speed_bonus", "key": "mining", "value": 0.15 } ] } ] }
```
Perk ids are `<namespace>:<id>`; `requires` may omit the namespace when it is the same file's.

## XP tables — `urskills/xp_sources/<file>.json`
Triggers: `break_block` (blocks), `fish`, `smelt`, `craft`, `brew`, `consume` (items).
```json
{ "skill": "mining", "trigger": "break_block", "entries": [
  { "match": "#minecraft:iron_ores", "xp": 15 }, { "match": "minecraft:wheat", "xp": 4, "mature_only": true } ] }
```
Combat, armor, block, sneak, agility, speech (trading), enchanting, lockpicking and pickpocket XP are coded.

## Requirements — `urskills/requirements/<file>.json`
`kind`: `tool`, `weapon`, `armor`, `block`. Enforcement (OFF / SOFT / HARD) is set per kind in the server config.
```json
{ "requirements": [ { "match": "minecraft:diamond_pickaxe", "kind": "tool", "skill": "mining", "level": 30 } ] }
```

## Classes — `urclasses/classes/<id>.json`, birthsigns — `urclasses/birthsigns/<id>.json`
```json
{ "name": "Warrior", "tagline": "...", "description": "...", "icon": "minecraft:iron_sword", "order": 1,
  "skills": { "one_handed": 15, "block": 12 }, "effects": [ ... ], "coins": 40,
  "loadout": [ { "id": "minecraft:iron_sword" }, { "id": "minecraft:bread", "count": 8 } ] }
```
Birthsigns: `name`, `description`, `icon`, `order`, `effects`.

## Quests — `urquests/quests/<path>.json`
```json
{ "title": "The Miner's Plight", "description": "...", "category": "side", "giver": "urnpcs:miner",
  "repeatable": false, "cooldown_minutes": 0, "pool": "bounty", "abandonable": true,
  "requirements": { "quests": ["urquests:main/a_new_beginning"], "skills": { "mining": 10 }, "level": 0 },
  "stages": [ { "description": "Mine coal and iron.", "objectives": [
      { "type": "mine", "target": "#minecraft:coal_ores", "count": 20, "text": "Mine coal ore" },
      { "type": "turn_in", "target": "urnpcs:miner" } ] } ],
  "rewards": { "coins": 80, "xp": { "mining": 500 }, "perk_points": 0, "items": [ { "id": "minecraft:diamond" } ] } }
```
Objective types: `kill` (entity), `collect` (item; `consume: true` takes them on completion), `talk`
(NPC id), `turn_in` (NPC id; only counts once every other objective in the stage is done), `visit`
(structure id or `#tag`), `biome`, `mine` (block), `craft`, `smelt`, `fish` (item), `skill` (target =
skill id, count = level), `level` (count = character level), `cast` (spell id) — and any custom type
another mod reports through `ProgressEvent`.

Quests with `"pool": "bounty"` appear on notice boards (3 per board per day by default).

## NPCs — `urnpcs/npcs/<id>.json`
```json
{ "title": "Blacksmith", "names": ["Bram", "Helga"], "skin": "urnpcs:blacksmith",
  "dialogue": "urnpcs:blacksmith", "shop": "urnpcs:smithy", "trainer": { "skill": "smithing", "max_level": 50 },
  "essential": true, "wander": 4, "equipment": { "mainhand": { "id": "minecraft:iron_sword" } },
  "greeting": "Used when there's no dialogue tree." }
```
`skin: "ns:name"` resolves to `assets/ns/textures/entity/npc/name.png` (generate with ArtForge).
Spawn with `/ur npc spawn <id>`.

## Dialogue — `urnpcs/dialogues/<id>.json`
```json
{ "entry": [ { "conditions": [ { "type": "quest_active", "target": "urquests:side/x" } ], "node": "waiting" },
             { "node": "greet" } ],
  "nodes": {
    "greet": { "text": "Hello.", "options": [
      { "text": "Any work?", "next": "offer", "conditions": [ { "type": "quest_available", "target": "urquests:side/x" } ] },
      { "text": "Lower your prices. (Persuade)", "next": "yes", "check": { "skill": "speech", "level": 25, "fail": "no" } } ] },
    "offer": { "text": "...", "options": [ { "text": "I'll do it.", "actions": [ { "type": "start_quest", "target": "urquests:side/x" } ] } ] } } }
```
Conditions: `quest_active`, `quest_completed`, `quest_not_started`, `quest_available`, `quest_stage`
(+`value`), `skill` (+`value`), `level`, `has_item` (+`value`), `coins`, `flag`, `not_flag`; any can
be `"negate": true`. Actions: `start_quest`, `give_item` (+`item`), `take_item`, `give_coins`,
`take_coins`, `give_xp`, `set_flag`, `clear_flag`, `open_shop`, `train`, `end`. An option without
`next` ends the conversation. "Shop", "Train" and "Goodbye" options are added automatically.

## Shops — `urnpcs/shops/<id>.json`
```json
{ "name": "The Smithy",
  "sells": [ { "item": { "id": "minecraft:iron_sword" }, "price": 60 } ],
  "buys":  [ { "match": "minecraft:iron_ingot", "price": 5 }, { "match": "#c:gems", "price": 15, "display": "minecraft:emerald" } ] }
```
Prices shown to players include Speech level and `price_bonus` effects.

## Settlements — `urnpcs/settlements/<id>.json`
```json
{ "structures": "#minecraft:village", "always": ["urnpcs:village_elder"], "random": ["urnpcs:blacksmith"],
  "random_count": 5, "notice_board": true, "radius": 16 }
```
Add entries for other mods' towns (e.g. Towns & Towers structure ids) to bring them to life too.

## Spells — `urmagic/spells/<id>.json`
```json
{ "name": "Firebolt", "description": "...", "school": "destruction", "level": 10, "cost": 25, "cooldown": 16,
  "kind": "projectile", "damage": 7, "speed": 1.8, "element": "fire", "xp": 8 }
```
Kinds: `projectile`, `cone`, `lightning`, `self`, `area` (`area`: undead / glow / calm / fear / heal /
default=damage hostiles), `summon` (`entity`), `bound_weapon`. Elements: fire, frost, shock, holy,
heal, shadow, arcane. `effects` apply mob effects. Icons: `assets/<ns>/textures/gui/spell/<id>.png`.
